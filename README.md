# n5za.github.io

**The Annoying Site** — a browser API abuse demo.

Shows what a webpage can (and shouldn't) do with browser APIs: pop-up windows,
notification permission spam, screen manipulation, focus stealing and more.

> Educational demo only. Respect browser permissions and the user.

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Deploy

Served via GitHub Pages at <https://n5za.github.io/>.
